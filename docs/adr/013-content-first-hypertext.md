# ADR 013：内容优先的博客导航与超文本阅读

## 状态

已采纳。

## 背景

站点已经具备沉浸式开场、每日互动、搜索、阅读进度和知识关系，但首页的真实文章出现得偏晚，归档只有标题级信息。访客需要先理解多个功能区，才能判断一篇内容是否值得阅读。

## 参考模式

- Derek Sivers 与 Adactio：清晰、按时间组织、无需学习界面的文章索引。
- Maggie Appleton：用主题与标签支持非线性漫游。
- Andy Matuschak：稳定、可引用的概念和章节链接。
- Gwern：渐进增强、快速访问正文，以及强调超文本关系。

## 决策

- 首页开场继续保留，但开场后的第一条主要内容流改为最新文章，不依赖人工精选。
- 每日互动和访客导览保留在内容流之后，趣味层不抢占阅读任务。
- 归档同时展示摘要、标签、分类和阅读时间，使访客在点击前形成预期。
- 文章显示友好日期、明确返回入口，章节标题本身成为可复制的稳定链接。
- 推荐标记只作为视觉强调，不再改变时间顺序。

## 结果

首次访客可以更快到达真实内容，回访者仍保留个性化连续性；归档兼顾时间浏览与主题漫游；深链接改善分享、引用和返回定位。
