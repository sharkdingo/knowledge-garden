# ADR 011：生产闭环与首发路径

状态：已接受

## 决策

- 公开阅读与 Studio 写入继续位于同一个模块化单体，但由应用服务和仓储接口隔离。
- Studio 提供分类管理，保证空数据库也能完成“分类 → 草稿 → 发布”的首发闭环。
- 全站搜索索引只在访客打开搜索时，通过轻量投影接口加载；常规页面不读取正文。
- `site_settings.profile` 使用显式 `schemaVersion`，运行时读取必须校验；编辑使用更新时间版本进行乐观并发控制。
- 健康检查同时验证关键表、最新迁移和配置模式。
- Studio 提供受保护的可移植 JSON 快照；生产环境另需平台级定期备份。

## 后果

这些边界避免 UI 直接依赖 D1、降低公共页面读取放大，并让本地与生产故障更容易诊断。当前仍保持单体部署，以避免在流量和团队规模尚未证明需要时引入分布式复杂度。
