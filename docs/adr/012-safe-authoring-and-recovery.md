# ADR 012：并发安全的创作与可演练恢复

## 状态

已采纳。

## 背景

主人可能在多个标签页或设备中编辑文章、题解、项目和站点设置。仅按主键更新会让较晚提交的旧页面静默覆盖新内容。与此同时，只有导出能力的备份不能证明数据能够安全恢复。

## 决策

- 所有核心编辑聚合使用持久化版本号，写入必须携带 `If-Match`。
- 带子表的文章与题解使用短期写入令牌守卫关系表变更，根记录版本不匹配时，子表写入也不会执行。
- 写操作经过统一的内容类型、大小和同源边界，并记录不含原始邮箱的结构化审计事件。
- JSON 恢复采用两阶段交互：先校验和预演，再输入与快照校验和绑定的确认代码。
- 恢复应用前保存当前数据库快照；内容替换通过 D1 批处理提交。
- CI 在隔离临时项目中从零迁移真实本地 D1，并通过 HTTP 走完主人和访客的关键旅程。

## 结果

陈旧页面会收到明确冲突，不再静默覆盖。备份从“可下载”升级为“可验证、可确认、可恢复”。复杂性集中在应用服务和基础设施适配器，页面只负责交互状态。
